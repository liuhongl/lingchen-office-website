# 内容真源逐字文案台账

## 使用规则

- 一个内容真源文本节点对应一行，不合并不同节点。
- `内容真源逐字原文`必须保留标点、数字、单位、英文大小写、英文空格和括号。
- 长文案必须填写首句、末句和完整句数。
- 只有用户明确确认的内容才能写入“用户覆盖”。
- 看不清的内容标记 `BLOCKED`，禁止概括、缩写、润色或猜测。
- “已核对”只有在页面实际渲染字符串与有效原文一致后才能填写 `PASS`。
