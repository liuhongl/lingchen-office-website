## 全页回归

- [ ] 所有文本节点均有已声明内容真源的证据和代码位置。
- [ ] 没有概括、缩写、润色、补写、漏句或误录。
- [ ] 用户确认覆盖项均有记录。
- [ ] 公共 Header/Footer 未被页面级样式覆盖。
- [ ] 全页同视口截图已核对。
- [ ] `scrollWidth === clientWidth`。
- [ ] 重复组件及共享样式无跨区块污染。
- [ ] 公共组件交付哈希与开工哈希一致，或有用户授权记录。
- [ ] 所有图标/图片/SVG 均与视觉台账的素材来源一致。
- [ ] 可导出的设计图标均来自 MasterGo 原始图层，优先 SVG；不存在截图裁图或未经批准的图标库替代。
- [ ] 位图源尺寸至少为 CSS 显示尺寸 2×，且未被 Flex 或 CSS 拉伸；导出文件已单独检查完整性和清晰度。
- [ ] 浏览器实际加载字体及字重与视觉台账一致，没有 synthetic bold。
- [ ] 背景色、渐变色标和方向已由取值/叠加证据核对，不凭肉眼近似。
- [ ] 所有预约、体验、演示和合作咨询 CTA 均通过 `BookingTrigger` 打开公共 `BookingModal`。
- [ ] 公共弹窗的关闭按钮、遮罩、Escape、滚动锁定、键盘焦点和本轮纳入视口下的显示已验证；移动端未纳入时已在下方明确记录。
- [ ] 非预约 CTA 的行为例外均已记录在 `scope.md`。
