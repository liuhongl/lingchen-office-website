# MasterGo 视觉属性台账

## 使用规则

- 一个可独立核对的视觉元素对应一行；文字节点也要记录字体属性。
- 所有数值和颜色来自 MasterGo 研发模式或可测量证据，不写“约”“类似”“看起来”。
- 图标必须记录 MasterGo 原始 `layer_id` 和导出文件；禁止凭语义换成相近图标。仅当视觉真源不存在正式素材且用户明确授权时，才允许语义生成 SVG，并记录为“不适用（用户授权语义生成）”。
- 矢量优先 SVG；位图源尺寸至少为 CSS 显示尺寸的 2 倍，并记录 DPR。
- 禁止从截图裁图。导出后必须单独打开检查非透明内容、裁切、居中和清晰度。
- 渐变必须记录方向、色标、位置和作用范围；字体必须确认实际加载的 family/weight。
- 看不清或无法读取时填写 `BLOCKED`，该区块不得实现。
