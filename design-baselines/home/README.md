# 首页 MasterGo 视觉基线

来源：MasterGo 文件 `198643424708731`，页面 `6:2027`，桌面画板，100% 缩放。

## Header

- 白色固定头部，底部细描边。
- 左侧使用正式灵宸 Logo，小尺寸展示。
- “首页”为蓝到青渐变胶囊按钮，白字并带蓝色投影。
- 右侧显示青色圆点和“明道 · 优术 · 取势 · 合众”。
- “立即体验”为蓝到青渐变按钮。

## Hero

- 研发模式外层 `组 4`：`width: 1440px; height: 722.3px;`，本地以 Header + Hero 总高度对齐。
- 研发模式显示 `background: url(组 4.png);`，这是整组导出预览，不直接作为网页背景图使用，避免把文字按钮烙进背景。
- 首屏为白色到右上浅蓝的渐变背景，底部有浅蓝分隔带；不使用左下白色圆圈装饰，不使用明显网格。
- 顶部提示使用青色圆点，不使用星光图标。
- 主标题深色粗体；“新质生产力”为蓝到紫再到粉色的渐变。
- 中部信息卡为浅色描边大卡，左侧蓝青渐变小卡，右侧保留原文层级。
- 两条使命文案分别使用青色和紫色前置圆点。
- “查看产品矩阵”为蓝青渐变按钮；预约按钮为白底描边。
- “查看产品矩阵”和“预约产品演示与体验”默认状态不显示按钮边框。

## 问题与业务方向

- 研发模式外层 `组 34`：`width: 1440px; height: 708.13px; background: #EAF5FF;`。
- 浅蓝背景，当前已按研发模式记录为 `#EAF5FF`；左侧标题和问题列表，右侧两大核心业务方向白色卡片。
- 问题标题为粗体，前置“浅色外圈 + 红色实心点”，列表项之间没有横向分隔线。
- 右侧两类业务使用 `01/02` 渐变编号和独立描边卡片，不使用业务图标；检查项纵向排列。
- 底部总结条中首句为深色粗体，“高并发、智慧化、批量、合规”分别为蓝、青、紫、粉。

## 产品理念与指标

- 研发模式外层 `组 88`：`width: 1440px; height: 616px; background: #F4FAFF;`。
- 整区为浅蓝背景 `#F4FAFF`。
- 标题文字层：`font-size: 32px; font-weight: bold; line-height: 48px; color: #0B1633;`。
- 标题为错位排版：左侧标题换两行，右侧“可交付商业结果”为蓝紫粉渐变并与“的生产力。”同处第二行。
- 四张白色指标卡使用“顶部 3px 强色线 + 其余三边 1px 同色描边”，依次为蓝、青、紫、粉，对应数字同色。
- `50%+`、`90%~95%+`、`300%+`、`500%+` 为超粗字重，按 `font-weight: 900` 处理。
- 指标卡和底部提示条之间约 48px。
- 底部提示条三组文字和圆点依次为蓝、青、紫。

## Agent OS

- 研发模式外层 `组 111`：`width: 1440px; height: 1221.25px; background: #EAF5FF;`。
- 研发模式资源包含多组 SVG 轨道/弧线，例如 `230×53.33`、`20×220`，后续圆环细节应优先复用或按该资源尺寸还原。
- “自主进化的”和“智能体内核”为深色粗体；仅“Agent OS”为蓝紫粉渐变。
- 六个约 200px 的白色圆形节点围绕中心内核；节点顶部色块在圆形内部露出弧形，不是圆外短线或整圈边框；编号使用对应的纵向渐变文字，标签按蓝、青、紫、粉分色。
- 主轨道由六段柔化椭圆弧组成，并叠加两层极淡的虚线内圈，不能用连续实线椭圆代替。
- 中心内核约 200px，蓝紫渐变，包含两层同心细线、单行“自进化 Agent OS”和三个状态圆点。
- 定位、承诺、愿景卡片不使用大图标，标题前使用小圆点，强调文字分别为蓝、紫、青。
