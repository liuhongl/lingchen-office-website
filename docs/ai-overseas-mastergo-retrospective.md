# AI 出海获客与合规解决方案还原复盘

## 适用范围

适用于 MasterGo 页面 `6:20764`「解决方案-综合-AI出海获客与合规解决方案」，也作为后续解决方案页的防错清单。

## 本轮暴露的问题

1. 将 MasterGo 的选中框、蓝色边界线或标尺辅助线误当成页面描边。
2. 在设计稿原文之外补充“AI Agent OS 智能体内核”等推断文案。
3. 只实现信息结构，遗漏标题前圆点、外环圆点、局部字重、时间轴连线和提示图标。
4. 复用相近组件，导致“下一步建议”等模块的背景、边框和布局被错误覆盖。
5. 只设置 CSS `font-weight`，没有核对设计字体是否真实具备对应字重，导致指标数字和 CTA 标题偏细。
6. 用整页高度接近替代逐区叠加检查；局部误差可能互相抵消，总高度不能证明视觉一致。
## 强制防错规则

### 设计状态与内容

- 截图前必须解除图层选中，并关闭可能影响判断的标尺、布局网格和像素网格。
- 设计稿中不存在的文案、标签、指标、徽标和功能不得新增。
- 看不清的文案标记待确认，不得根据上下文补写。
- 用户明确确认的替换文案可以覆盖设计稿原文；本页已确认用“统一知识中枢 + 数据飞轮”替换错误补写内容。

### 特殊视觉元素

- 标题圆点、中心点与外环、时间轴连线、提示图标必须作为独立元素或明确伪元素实现，不能用原生列表符号近似。
- 渐变、局部加粗、数字字重和换行范围必须逐字符核对。
- 指标数字必须核对字体、字号、字重、行高和字间距；不能只依赖 `<strong>` 默认表现。
- 相似的信息条不得直接复用同一背景样式，必须分别记录背景、描边、圆角、图标和内边距。

### 验收

- 每个区块都要保存无编辑器干扰的 MasterGo 基线和本地同视口截图。
- 对照至少覆盖：边界、宽高、间距、换行、字体、字重、颜色、渐变、圆角、阴影和特殊图形。
- 检查 `document.documentElement.scrollWidth === document.documentElement.clientWidth`。
- lint、TypeScript 和 build 通过只代表工程可运行，不能代替视觉验收。
- 没有同视口叠加或差异证据时，不得汇报“1:1 验证通过”。
