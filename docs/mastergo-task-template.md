# MasterGo 页面实现请求模板

项目默认遵守根目录 `AGENTS.md`，通常不需要重复粘贴完整规则。新任务只需提供：

```text
请严格按照 AGENTS.md 和 mastergo-pixel-implementation Skill 实现。

MasterGo 页面：<页面名称或 page_id>
目标图层：<layer_id，可选>
本次范围：<页面或具体区块>
补充来源：<原型、文章或正式素材，可选>
禁止改动：<不允许修改的区域，可选>

按“设计证据 → 分区实现 → 同视口截图对比 → 工程验证”的顺序执行；
没有视觉对比证据，不得报告 1:1 完成。
```

最简用法：

```text
按项目 AGENTS.md 严格还原 MasterGo 的「产品矩阵」页面，本次只做桌面端。
```
