# 灵宸研究院文章还原规则

## 1. 目标与事实来源

本规则适用于“灵宸研究院”28 篇 DOCX 文章向官网详情页的转换、实现与验收。

事实来源优先级：

1. 对应文章的原始 DOCX：决定文章标题、正文、标题层级、段落顺序、列表、图片、图注、表格及其相对位置。
2. 用户已确认的覆盖项：决定 Word 分页、标题双字段、日期和列表封面等发布口径。
3. MasterGo 文章画板：只决定详情页公共视觉外壳和通用组件样式，不覆盖文章内容与内容块顺序。
4. 现有代码：只作为工程实现参考，不得反向覆盖 DOCX 或 MasterGo。

MasterGo 参考：

- 链接：`https://mastergo.com/file/198643424708731?fileOpenFrom=team&page_id=6%3A26021&devMode=true&layer_id=6%3A07886`
- `page_id`：`6:26021`
- `layer_id`：`6:07886`
- 画板：1440×7709
- 定位：文章详情页视觉参考，不是其余 27 篇文章的逐段视觉真源。

## 2. 用户已确认口径

### A. 布局不变

“布局不变”定义为保持文章内容块的结构、顺序和相对位置：

- 段落顺序不变。
- 标题层级与章节顺序不变。
- 图片所在章节及前后位置不变。
- 图注与对应图片的关系不变。
- 表格所在位置、行列、合并关系和单元格顺序不变。
- 列表、引用和提示框所在位置不变。

不保留 Word 的 A4 纸张分页、页码、页眉、页脚、固定页高、纸张边距和因分页形成的空白。网页采用内容驱动高度与响应式布局。

### B. 标题双字段

- `displayTitle`：研究院列表页使用 MasterGo 已确认的展示标题。
- `sourceTitle`：详情页唯一 `h1` 使用 DOCX 原始标题。
- 两个字段分别保存，禁止用其中一个批量覆盖另一个。

### C. 日期

- 未获得正式发布时间表前，详情页和新增文章卡片不展示发布日期。
- 禁止把文件创建时间、修改时间、压缩包时间或模型推断值作为发布日期。
- 现有列表页日期也不得作为详情页的事实来源；后续是否保留由列表页单独审计决定。

### D. 列表封面

- 封面只用于研究院列表卡片右侧现有视觉区域，不进入文章正文，不改变正文图片位置。
- 前 6 篇继续使用 MasterGo 已导出的正式卡片素材。
- 后 22 篇先审计是否存在适合缩略展示的文章原始图片；使用时复制原始文件，不从正文移除。
- 不适合缩略展示时标记 `COVER_BLOCKED`。
- 禁止裁切含文字的流程图、放大低分辨率图片、复用其他文章插画、截图裁图或自动生成近似封面。
- 分类通用封面属于新的列表页设计扩展，必须另行取得用户确认。

## 3. 内容零增删改

文章正文必须字符级保真：

- 保留全部文字、标点、数字、单位、英文大小写、英文空格和括号。
- 保留原始段落边界、显式换行和行内强调。
- 保留标题、正文、列表、图片、图注、表格、引用和提示框的原始顺序。
- 原文疑似错字、重复、口径冲突或不通顺时保持原文并标记 `CONTENT_REVIEW`，未经用户确认不得修改。
- SEO description 只能使用原文已有摘要或原文连续摘录，不得生成新观点。
- 面包屑、分类标签等网站导航必须与正文容器分离，不能混入正文字符审计。

严禁：

- 自动总结、润色、纠错、补标题、补结论或补 FAQ。
- 合并短段、拆分长段、删除重复内容或调整章节顺序。
- 为页面更美观而移动图片、表格、图注或提示框。
- 将图片里的文字再次转写进正文造成重复。
- 使用 `dangerouslySetInnerHTML` 承载未经约束和审计的整篇转换结果。

## 4. 结构映射规则

转换器只允许做确定性的结构映射，不能基于语义重写内容。

| DOCX 结构 | 网页结构 | 保真要求 |
|---|---|---|
| 文章原始标题 | `h1` | 逐字一致 |
| Heading 1/2/3 | `h2`/`h3`/`h4` | 层级与顺序一致 |
| 普通段落 | `p` | 字符、段落边界和行内强调一致 |
| 有序/无序列表 | `ol`/`ul` | 顺序、嵌套与每项文字一致 |
| 正文图片 | `figure > img` | 原始文件、顺序和比例一致 |
| 图注 | `figcaption` | 原文与对应关系一致 |
| 数据表格 | `table` | 行列、合并关系与单元格文字一致 |
| 单格提示表 | `aside`/`blockquote` | 文字、位置和语义不变 |
| 分页符 | 不输出 | 不制造网页空白 |
| 页眉/页脚/页码 | 不输出 | 不属于文章正文 |

遇到无法确定的结构必须标记 `STRUCTURE_BLOCKED`，禁止猜测后继续。

## 5. 图片规则

- 从 DOCX 的 `word/media/` 提取原始字节，不通过 Word 页面截图获取。
- 每张图片记录源 DOCX、media 路径、格式、像素尺寸、SHA-256、正文块位置、图注和实现路径。
- 使用原始宽高比，禁止非等比拉伸。
- 浏览器显示尺寸不得超过原始素材可支持的清晰度；不足时标记 `ASSET_BLOCKED`。
- 含文字的流程图默认完整展示，禁止为了填满容器裁切。
- 移动端允许按容器缩小；若缩小后不可读，提供横向滚动或点击查看原图，不重排图内内容。
- 图片文件存在不等于通过，必须单独打开检查完整性、透明边界、居中、清晰度和内容语义。

## 6. 表格与提示框规则

- 真正的行列数据必须使用语义化 HTML `table`，不能转成图片。
- 保留表头、行列顺序、合并单元格和所有文字。
- 桌面端按原始行列展示；移动端宽表默认横向滚动。
- 未经逐表确认不得将表格重排为卡片，也不得交换行列。
- DOCX 中只承担提示/引用作用的单格表格可以映射为 `aside` 或 `blockquote`，但内容、所在位置和强调关系不变。
- 无法判断表格是数据还是布局容器时标记 `TABLE_BLOCKED`。

## 7. 详情页视觉边界

MasterGo `6:07886` 只用于确定：

- 页面背景和详情页公共外壳。
- 面包屑、分类、文章头部和正文容器宽度。
- 标题、正文、章节标题、图注和表格的通用字体体系。
- 通用间距、圆角、边框、浅色信息块和底部区域的视觉语言。

MasterGo 不用于决定：

- 各文章的章节数量、段落数量、图片数量或表格数量。
- 某篇文章的内容块高度和全页总高度。
- 原文不存在的摘要、作者、日期、结论、FAQ、CTA 或相关推荐文案。

禁止以画板总高 7709px 为目标写死详情页高度。文章高度必须由原始内容自然产生。

## 8. 数据与路由

- 正式路由：`/research/[slug]`。
- `slug` 使用稳定、可读的英文小写形式；发布后修改必须提供永久重定向。
- 每篇文章使用结构化、可审计的 block 数据，不在页面组件中手写整篇长文。
- 推荐字段：`slug`、`category`、`displayTitle`、`sourceTitle`、`summary`、`publishedAt`、`cover`、`blocks`、`sourceDocxSha256`。
- `publishedAt` 在正式日期确认前为 `null`，页面不得渲染占位日期。

## 9. 逐篇门禁

每篇文章必须依次通过：

1. `SOURCE`：原始 DOCX 文件名、SHA-256、段落/图片/表格数量已登记。
2. `CONTENT`：原文块顺序与逐字台账完成，无未解释差异。
3. `ASSET`：所有图片已原始提取并逐张检查。
4. `STRUCTURE`：标题、列表、图注、表格和提示框映射已核对。
5. `RENDER`：桌面与移动端实际渲染无裁切、重叠、溢出或错序。
6. `SEO`：独立元数据、自指 canonical、唯一 h1、Article Schema、sitemap 和内链完成。
7. `ENGINEERING`：lint、类型检查、构建和 diff check 通过。

上一门禁未通过，不得进入下一篇批量实现。三类代表样板未通过前，不得批量转换剩余文章。

## 10. 完成等级

- `已提取`：结构化数据与素材已生成，尚未完成逐字和视觉验收。
- `内容核对通过`：字符、顺序、表格和素材与 DOCX 一致，尚未完成详情页视觉验收。
- `已视觉校准`：详情页已按参考外壳完成桌面/移动端验证。
- `文章还原验收通过`：内容、结构、素材、视觉、SEO 和工程门禁全部通过，且没有未说明的 `BLOCKED`。

没有逐篇证据时，不得用“批量转换成功”代替 28 篇分别验收。
