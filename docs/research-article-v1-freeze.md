## 3. DOCX 样式映射

- 原始字体颜色按 run 提取到 `segments.color`，只渲染 DOCX 明确色值。
- 未设置直接颜色的正文使用模板默认正文色，不推断局部配色。
- 首篇已验证色值：主标题 `#1A1A1A`、章节与重点 `#1F4E79`、关键词正文 `#595959`。
- 加粗、斜体、下划线与颜色均按原始 run 保存；所有 segments 拼接必须逐字符等于原段落 text。
- DOCX 段落缩进、字号、行距、段前段后、对齐、底纹和左边框必须逐段提取，不再统一猜测。
- 两篇普通正文首行缩进为 `480 twips = 32px`；“其一/其二/其三”原文无首行缩进，按 0 渲染。
- 普通正文为 12pt、1.5 倍行距、段后 100 twips；章节标题为 14pt、段前 320 twips、段后 160 twips。
- 摘要、关键词、标题、行动/落地建议、图注和表格不套用普通正文的首行缩进。
- 行动/落地建议与摘要使用 DOCX 同源段落样式：`#F4F6FA` 底纹、`#2E5FA3` 左边框、11pt、`340/240` 倍行距，无圆角；两者应使用同一背景色，仅通过内容与页面位置区分。

## 4. 允许逐篇变化

- `displayTitle`、`sourceTitle`、副标题、摘要、关键词。
- 分类与稳定 slug。
- 章节数量、段落数量、标题层级和行内直接格式。
- 图片数量、图注、图片比例和正文位置。
- 表格数量、行列、单元格内容和合并关系。
- DOCX 明确存在的字体颜色。

## 5. 禁止逐篇漂移

- 不改变 1180px 公共网格。
- 不把标题改回左对齐、渐变标题、深色 Hero 或胶囊标签。
- 不增加文章日期、作者、FAQ、相关推荐或 CTA。
- 不改变纯白页面背景、摘要顶部 40px 官网留白或重新增加横线；摘要内部样式以 DOCX 直接属性为准。
- 不为了缩短页面合并段落、移动图片或重排表格。
- 不把列表 `displayTitle` 覆盖详情页 `sourceTitle`。

## 7. 批量化 Stop Rule

在三类代表样板全部通过前，不启动剩余文章的无差别批量发布：

1. 复杂图表型：Agent OS，已通过。
2. 强合规、多表格型：AI 催收合规工程，已通过。
3. 长文、多图片、无数据表型：待第三篇验证。

任一代表样板出现内容丢失、表格误判、字体颜色遗漏或响应式问题，先修正转换规则并回归前序样板，再继续下一篇。
