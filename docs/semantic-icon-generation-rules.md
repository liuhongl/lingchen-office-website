# 官网语义图标生成授权规则

## 1. 授权范围

- 生效日期：2026-07-22。
- 用户已明确授权：本官网仓库内的页面在没有正式图标素材时，可以按业务语义制作 SVG。
- 该授权是官网级持续授权，覆盖当前和后续新增的正式官网页面，无需逐页重复询问。
- 明确包含但不限于：
  - `/solutions/products/` 下 7 个产品专项解决方案页面。
  - `/solutions/ai-overseas/`、`/solutions/non-performing-assets/`、`/solutions/legal-ai/` 3 个综合解决方案页面。
  - `/about/` 关于灵宸页面。
  - `/products/` 下 7 个产品矩阵详情页面。
  - 首页、客户案例、研究院、联系页以及本仓库后续新增的其他正式官网页面。
- 本授权只适用于当前官网仓库，不自动扩展到独立后台、管理系统、小程序、AI Call、第三方落地页或其他项目。
- 本规则只定义图标生成授权，不改变各页面已经确认的内容真源和视觉真源；整个官网的桌面端验收范围统一执行 `docs/website-desktop-only-scope.md`。

## 2. 正式素材优先级

每个图标必须按以下顺序检查：

1. 当前视觉真源中存在可识别、可导出的 MasterGo 原始图层时，必须导出正式素材。
2. 用户提供了正式素材时，必须优先使用用户素材。
3. 项目中已有经过验收、语义一致且属于同一视觉体系的正式图标时，可以复用，并记录源文件与复用依据。
4. 完成上述检查仍没有对应正式素材时，才适用本授权制作新的语义 SVG。

不得因为已经获得官网级授权，就跳过 MasterGo 图层、用户素材或项目正式素材检查。

## 3. 语义生成要求

- 先定义业务语义，再设计图形；禁止先找一个通用图标再反向解释。
- 参考当前页面视觉真源以及项目已确认 MasterGo 图标的网格、圆角、描边、留白和配色。
- 同一组件组内统一 `viewBox`、安全边距、描边粗细、端点、连接方式、颜色层级和 CSS 显示尺寸。
- 默认制作独立 SVG 文件，不使用 Emoji、Unicode 字符、截图裁图或未经登记的第三方图标库。
- 避免机器人头像、AI 大脑、魔法棒、无语义闪光、随机星芒和渐变球等模板化“AI 味”表达，除非内容真源明确要求该语义。
- 图标只能表达页面已有业务含义，不得借图标新增卖点、指标、功能或事实。
- 业务语义存在多种会明显改变用户理解的合理解释时，仍需就该具体语义向用户确认。

## 4. 证据记录

每个新制 SVG 必须在当前页面 `visual-ledger.md` 记录：

- 页面、区块、卡片或按钮及其业务语义。
- 来源类型：`用户授权语义生成`。
- `MasterGo layer_id`：`不适用（已确认无对应正式素材）`。
- 已检查的 MasterGo、用户素材和项目素材位置。
- 参考的既有图标组或视觉语言。
- `viewBox`、源尺寸、CSS 尺寸、描边、颜色、文件路径和 SHA-256。
- 原始文件完整性、居中、安全边距、语义一致性和页面渲染结论。

## 5. 验收门禁

1. 单独打开 SVG，确认没有空白、残缺、错误裁切和语义错配。
2. 在当前页面目标桌面视口检查实际宽高、位置、颜色、清晰度和同组一致性。
3. 批量核对页面图标数量与视觉台账一致，并确认浏览器全部加载完成。
4. 当前只在页面桌面目标视口验收；移动端重新纳入官网范围后，再另行补充移动端图标验收。
5. 正式素材检查、视觉台账或实页验收任一缺失时，只能报告实际进度，不得将图标标记为完成。
